# 🛒 ShopEase Frontend

A responsive Amazon-style ecommerce website built using **HTML, CSS, and JavaScript**.

This project simulates core ecommerce features such as product listing, search, cart functionality, checkout, and order summary.

---

## 🚀 Live Demo

https://shopease-store-taupe.vercel.app/

---

## 📌 Features

* Product listing page
* Search products
* Add to cart functionality
* Cart quantity counter
* Checkout page
* Order summary
* Delivery options
* Indian currency (₹)
* Category filtering
* "Added to Cart" animation
* Responsive design

---

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6 Modules)

## ⚙️ Installation

1. Clone the repository

```
git clone https://github.com/Tharun-301/amazon-clone.git
```

2. Open the project folder

3. Run the project by opening

```
index.html
```

in your browser.

---

## 🌐 Deployment

This project is deployed using **Vercel**.

Steps:

* Push project to GitHub
* Import repository in Vercel
* Click Deploy
